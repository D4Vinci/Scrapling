# قوالب العناكب الخاصة بالمنصات {#platform-spider-templates}

تغطي القوالب العامة *أنماط الزحف*، مثل متابعة الروابط وقراءة خرائط الموقع. أما قوالب المنصات فتغطي *منصات إنشاء المواقع* التي تعرض بياناتها ببنية موحدة قابلة للقراءة برمجيًا عبر مواقع مستقلة كثيرة. لذلك يعرف العنكبوت مسبقًا أين توجد البيانات، وكل ما عليك هو تحديد النطاق.

## ShopifySpider {#shopifyspider}

يستخرج `ShopifySpider` جميع المنتجات من أي متجر يعمل على Shopify باستخدام JSON API الخاص بالمنصة، دون قراءة HTML الموقع.

```python
from scrapling.spiders import ShopifySpider

class MyStore(ShopifySpider):
    target_website = "example.com"

result = MyStore().start()
print(result.items[0])
```

اضبط `target_website` على نطاق المتجر. إذا كان فارغًا، يستخدم العنكبوت أول قيمة في `start_urls`، ثم `allowed_domains`. ويرفع `ValueError` إذا كانت القيم الثلاث كلها فارغة. إذا أعطيته URL كاملًا، يستخرج النطاق منه تلقائيًا.

### كيف يعمل {#how-it-works}

1. يقرأ صفحات `https://<store>/collections.json`، بحد أقصى 250 مجموعة في الصفحة، وهو الحد الذي تضعه المنصة.
2. لكل مجموعة تشير إلى وجود منتجات فيها، يقرأ صفحات `/collections/<handle>/products.json`.
3. يُخرج عنصرًا لكل خيار منتج، أي variant، ويمنع تكرار الخيارات التي تظهر في أكثر من مجموعة.

### حقول البيانات {#item-fields}

| الحقل | المصدر |
|-------|--------|
| `name` | اسم المنتج، مع اسم الخيار إذا لم يكن الخيار الافتراضي |
| `price` | سعر الخيار كنص، تمامًا كما تعيده Shopify |
| `category` | معرّف المجموعة مع تحويل بداية كل كلمة إلى حرف كبير، مثل `summer-sale` الذي يصبح `Summer Sale` |
| `brand` | بائع المنتج |
| `identifier` | معرّف خيار المنتج |
| `sku` | قيمة SKU للخيار، أو `""` إذا لم يحددها المتجر |
| `stock` | القيمة `None` إذا كان الخيار متوفرًا، و`0` إذا نفد المخزون |
| `image_url` | صورة المنتج الأولى، أو `""` |
| `url` | صفحة المنتج داخل المجموعة |
| `description` | محتوى `body_html` للمنتج بعد إزالة وسوم HTML |
| `old_price` | قيمة `compare_at_price` إذا كانت سعرًا فعليًا قبل التخفيض، وإلا `""` |
| `barcode` | باركود الخيار، أو `""`، لأن معظم المتاجر لا تعرضه في هذه المسارات |

هذه الحقول ليست إلزامية. أعد تعريف `_process_product()` في الكلاس الذي يرث من القالب لتغيير بنية العنصر أو استخراج حقول أخرى من بيانات المنتج.

### ملاحظات وحدود {#notes-and-limits}

- تعرض مسارات JSON المنتجات المنشورة على قناة المتجر الإلكتروني فقط. لذلك قد تكون قيمة `products_count` للمجموعة أكبر من عدد المنتجات الذي يمكن جلبه فعليًا. يستخدم العنكبوت هذه القيمة فقط ليقرر جلب المجموعة إذا كانت غير صفرية، ولا يتعامل معها كعدد متوقع للنتائج.
- غالبًا لن يعمل هذا القالب مع المتاجر التي تستخدم حماية إضافية أو كلمة مرور. وحتى إذا أمكن تشغيله، فقد تحتاج إلى إعادة تعريف أجزاء كثيرة منه.
- تظل كل ميزات `Spider` متاحة، بما فيها إعدادات التزامن وفترات الانتظار والالتزام بـ robots.txt ونقاط الاستكمال ودوال مراحل التشغيل.

### ما الذي يصلح ليكون قالب منصة {#what-qualifies-as-a-platform-template}

تُقبل قوالب المنصات التي تعرض بيانات ببنية موحدة قابلة للقراءة برمجيًا عبر مواقع مستقلة كثيرة، مثل Shopify. أما العناكب المخصّصة لموقع واحد فلا مكان لها في المكتبة، مهما كانت شهرة الموقع.
