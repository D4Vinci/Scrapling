# مرجع API لخادم MCP {#mcp-server-api-reference}

يوفر **خادم MCP في Scrapling** ست عشرة أداة لجمع بيانات الويب والتفاعل مع المتصفح عبر Model Context Protocol (MCP). يربط الخادم إمكانات Scrapling مباشرة بمساعدي AI، لتجمع البيانات من خلال المحادثة مع ميزات متقدمة لتجاوز أنظمة منع الروبوتات.

يمكنك تشغيل خادم MCP بالأمر التالي:

```bash
scrapling mcp
```

أو استيراد فئة الخادم مباشرة:

```python
from scrapling.core.ai import ScraplingMCPServer

server = ScraplingMCPServer()
server.serve(http=False, host="127.0.0.1", port=8000)
```

لتحديد ملف تشغيل متصفح متوافق مع Chromium لأدوات MCP التي تستخدم المتصفح، مرّر `executable_path`:

```python
server = ScraplingMCPServer(executable_path="/path/to/chromium")
```

## نموذج الاستجابة {#response-model}

تعيد أدوات الجلب وطلبات HTTP استجابة بالشكل الموحد التالي، باستجابة واحدة لكل استدعاء. تستخدم أدوات إدارة الجلسات النماذج الموضحة أدناه. تعيد `browser_screenshot` صورة للصفحة الحالية أو لعنصر واحد، مع رابط الصفحة، في كتلتي محتوى للصورة والنص. تعيد `browser_extract` و`browser_actions` نصًا عاديًا. تعيد أداتا الشبكة بيانات JSON منظمة باستخدام النماذج أدناه. تعيد `browser_evaluate` نتيجتها بصيغة JSON داخل كتلة نص عادي.

## نماذج طلبات الشبكة {#network-request-models}

تعيد `browser_network_requests` نموذج `NetworkRequestsModel` بالحقول `requests` و`next_cursor` و`has_more` و`dropped_count`. يحتوي كل `NetworkRequestInfo` على `id` و`url` و`method` و`resource_type` و`status`. مرّر `next_cursor` إلى `after_id` للمتابعة. تشير `has_more` إلى وجود نتائج مطابقة أخرى حاليًا.

تعيد `browser_network_request` نموذج `NetworkRequestModel` بالحقول `request_id` و`part` و`data` و`note`. تُعاد الملخصات والترويسات ككائنات، بينما يُعاد نص المحتوى المحفوظ كاملًا كسلسلة نصية، بما فيه نص استجابات JSON. يوضح `note` سبب غياب المحتوى أو عدم اكتمال الترويسات.

## فئة خادم MCP {#mcp-server-class}

فئة خادم MCP الأساسية التي توفر كل أدوات جمع بيانات الويب:

- **`make_request`**: تجلب رابطًا واحدًا عبر HTTP مع محاكاة المتصفح وإغلاق العميل تلقائيًا. تدعم GET وPOST وPUT وDELETE.
- **`browser_fetch_once`**: تجلب رابطًا واحدًا عبر متصفح متخفٍ يشغّل JavaScript ويتعامل مع Cloudflare، ثم تغلق المتصفح. استخدم جلسة مستمرة إذا أردت تنفيذ خطوات لاحقة أو قراءة سجل الشبكة.

- **`browser_extract`**: تقرأ الصفحة الحالية أو عنصرًا واحدًا بصيغة AI snapshot أو HTML أو Markdown أو نص، دون إعادة تحميل الصفحة. تحتفظ بنتائج النماذج والخطوات المنفذة على الصفحة. تتضمن snapshots أدوار العناصر وأسماءها ومراجعها ومواقعها وأحجامها. يعيد البحث باستخدام regex الأسطر المطابقة مع النص القريب والعناصر الأب.
- **`browser_actions`**: تنفذ سلسلة خطوات في استدعاء واحد: تحريك الماوس، والمرور فوق العناصر، والنقر، والتمرير، وملء الحقول، واختصارات لوحة المفاتيح، والرد على نوافذ الحوار، والانتظار. يمكنك قبول التنبيهات والتأكيدات أو رفضها، وإدخال نص في نوافذ الطلب. املأ حقل بحث وأرسله وانتظر النتائج وافتح نتيجة دون استدعاء مستقل لكل خطوة.

    تحدد أهداف الحركة والنقر باستخدام selectors أو مراجع snapshot أو الإحداثيات. عند استهداف عنصر، تنتظر الأداة ظهوره وتمرر الصفحة حتى يصبح مرئيًا. تدعم الحركة على عدة خطوات، والنقر بالأزرار الأيسر والأيمن والأوسط، والنقر المزدوج، وتمرير اللوحات المتداخلة.

    استهدف الحقول في أي مكان بالصفحة باستخدام selectors أو مراجع snapshot. أدخل نصًا، وحدد مربعات الاختيار أو ألغِ تحديدها، وحدد أزرار الاختيار، واختر خيارًا أو أكثر من القوائم الأصلية باستخدام نص الخيار. استبدل النص أو امسحه، أو اكتب عند موضع المؤشر الحالي. تعمل اختصارات لوحة المفاتيح على العنصر الذي يملك التركيز حاليًا. يضيف الوضع البطيء فترات توقف عشوائية بين الأحرف المكتوبة وبين كل الخطوات.

    انتظر ظهور المحتوى أو اختفاء طبقات التحميل باستخدام selectors أو مراجع snapshot. يمكنك أيضًا انتظار أحداث تحميل الصفحة أو استقرار نشاط الشبكة، أو إضافة فترة انتظار ثابتة قبل المتابعة.

- **`browser_evaluate`**: تشغّل JavaScript على الصفحة الحالية لاستخراج بيانات مخصصة أو حساب نتائج أو قراءة حالة التطبيق أو تحديث محتوى الصفحة. تدعم البرامج غير المتزامنة وتعيد نتائجها بصيغة JSON.
- **`browser_network_requests`**: تبحث في طلبات المتصفح المكتملة عبر علامات التبويب والتنقل والخطوات المنفذة. اعثر على استدعاءات API وأخطاء HTTP وعمليات إعادة التوجيه المحفوظة. تُخفى الموارد الثابتة افتراضيًا لتقليل حجم النتائج، ولا تُدرج الطلبات الفاشلة أو غير المكتملة. تعيد تفاصيل منظمة للطلبات مع تقسيم النتائج إلى صفحات.
- **`browser_network_request`**: تقرأ ملخص طلب مسجل أو ترويساته أو بياناته المرسلة أو نص استجابته بصيغة JSON منظمة، دون تكرار الطلب. تعيد الجزء المحدد كاملًا، بما فيه نص المحتوى المحفوظ. تبقى الاستجابات المحفوظة متاحة بعد تغير الصفحة، بما فيها استجابات HTTP من الفئتين 4xx و5xx. تظهر السجلات بعد اكتمال الحفظ. قراءة السجل وإغلاق الجلسة لا ينتظران اكتماله، وقد لا تُدرج عمليات الحفظ التي ما زالت تعمل عند التنقل أو الإغلاق. تأتي البايتات المحفوظة من Playwright وقد تختلف عن بايتات الخادم. يستخدم النص المسجل فك ترميز UTF-8 من Playwright عندما يكون صالحًا، وإلا يستخدم الترميز المعلن. تُقرأ وتُحفظ فقط أجسام الاستجابات ذات `Content-Type` النصي المدعوم. تحتفظ الأنواع الثنائية أو المفقودة أو غير المعروفة بالبيانات الوصفية والترويسات دون قراءة الجسم، ويستمر تحميل المتصفح كالمعتاد. تحد حدود الحجم من السجل المحفوظ. وقد توضح ملاحظة سبب عدم حفظ محتوى غير نصي أو كبير أو غير قابل للقراءة. اقرأ التفاصيل التي تحتاجها قبل إغلاق جلسة MCP.
- **`browser_fetch`**: تجلب صفحة عبر جلسة متصفح متخفٍ مفتوحة، وتستخرج HTML أو Markdown أو نصًا أو snapshot منظمة. يمكن أن تشمل snapshot الصفحة كلها أو عنصرًا محددًا، وتضم مراجع العناصر ومواقعها وأحجامها لاستخدامها في خطوات لاحقة.
