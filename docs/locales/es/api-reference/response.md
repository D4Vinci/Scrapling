# Clase Response {#response-class}

La clase `Response` contiene las respuestas HTTP de todos los fetchers. Permite acceder al estado, las cabeceras, el contenido y las cookies, y usar un `Selector` para analizar la respuesta.

Puedes importar la clase `Response` así:

```python
from scrapling.engines.toolbelt.custom import Response
```
