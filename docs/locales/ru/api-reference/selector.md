# Класс Selector {#selector-class}

`Selector` является основным классом Scrapling для разбора HTML и выбора элементов.

Здесь описаны все аргументы, атрибуты и методы `Selector`.

`Selector` можно импортировать прямо из `scrapling`:

```python
from scrapling.parser import Selector
```
