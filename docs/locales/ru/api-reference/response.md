# Класс Response {#response-class}

`Response` представляет HTTP-ответ, который возвращают все Fetcher. В нём доступны статус, заголовки, тело, cookie и методы разбора, унаследованные от `Selector`.

Класс `Response` можно импортировать так:

```python
from scrapling.engines.toolbelt.custom import Response
```
