# Шаблоны пауков для платформ {#platform-spider-templates}

Общие шаблоны описывают *схемы обхода*: переход по ссылкам или картам сайта. Шаблоны платформ предназначены для *платформ*, то есть конструкторов сайтов с одинаковой машиночитаемой структурой на множестве независимых сайтов. Паук уже знает, где искать данные. Вам нужно лишь указать домен.

## ShopifySpider {#shopifyspider}

`ShopifySpider` извлекает все товары из магазина на Shopify через JSON API платформы, не обращаясь к HTML сайта.

```python
from scrapling.spiders import ShopifySpider

class MyStore(ShopifySpider):
    target_website = "example.com"

result = MyStore().start()
print(result.items[0])
```

Задайте домен магазина в `target_website`. Если он пуст, паук берёт первую запись из `start_urls`, затем из `allowed_domains`. Если все три значения пусты, возникает `ValueError`. Полные URL автоматически преобразуются в домен.

### Как это работает {#how-it-works}

1. Загружаются страницы `https://<store>/collections.json`, по 250 коллекций на страницу. Это предел платформы.
2. Для каждой коллекции, в которой есть товары, загружаются страницы `/collections/<handle>/products.json`.
3. Для каждого варианта товара выдаётся одна запись. Варианты, встречающиеся в нескольких коллекциях, не дублируются.

### Поля записи {#item-fields}

| Поле | Источник |
|---------------|---------------------------------------------------------------------------|
| `name` | Название товара и название варианта, если это не вариант по умолчанию |
| `price` | Цена варианта: строка в том виде, в котором её возвращает Shopify |
| `category` | Часть URL с именем коллекции, преобразованная в слова с заглавной буквы: `summer-sale` становится `Summer Sale` |
| `brand` | Поставщик товара |
| `identifier` | ID варианта |
| `sku` | SKU варианта или `""`, если магазин его не задаёт |
| `stock` | `None`, если вариант доступен, и `0`, если его нет в наличии |
| `image_url` | Первое изображение товара или `""` |
| `url` | Страница товара внутри коллекции |
| `description` | `body_html` товара с удалёнными HTML-тегами |
| `old_price` | `compare_at_price`, если это настоящая цена до скидки, иначе `""` |
| `barcode` | Штрихкод варианта или `""`. Большинство магазинов не возвращают его в этих API |

Этот набор полей необязателен. Переопределите `_process_product()` в своём подклассе, чтобы изменить структуру записи или извлекать другие поля товара.

### Примечания и ограничения {#notes-and-limits}

- JSON API возвращает только товары, опубликованные в канале интернет-магазина. Поэтому `products_count` коллекции может быть больше числа доступных товаров. Паук использует его только как условие: если значение не равно нулю, нужно загрузить коллекцию. Это не ожидаемое число результатов.
- Шаблон, скорее всего, не будет работать с магазинами за дополнительной защитой или паролем. Даже если работу удастся наладить, потребуется переопределить много методов.
- Все возможности `Spider` сохраняются: число одновременных запросов, задержки, правила robots.txt, контрольные точки и хуки жизненного цикла.

### Какие платформы подходят для шаблонов {#what-qualifies-as-a-platform-template}

В библиотеку принимаются шаблоны для платформ с единой машиночитаемой структурой на множестве независимых сайтов, как у Shopify. Пауки для одного конкретного сайта не входят в библиотеку, каким бы популярным ни был сайт.
