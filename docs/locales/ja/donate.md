# 支援と広告 {#support-and-advertisement}

私は空いた時間にこれらのプロジェクトを開発し、費用と労力をかけて無料で公開しています。支援は、費用や日々の支出をまかない、既存のプロジェクトを改良し、新しいものを作る助けになります。コーヒーの補充にも使わせていただきます。

[GitHub Sponsors](https://github.com/sponsors/D4Vinci) または [Buy Me a Coffee](https://buymeacoffee.com/d4vinci) から支援できます。

ありがとうございます。これからも学び、試していきましょう。❤️

## 広告 {#advertisement}
コミュニティで会社を**宣伝**したい場合は、[広告プラン](https://github.com/sponsors/D4Vinci)をご覧ください。

### 1. [Silver プラン](https://github.com/sponsors/D4Vinci/sponsorships?tier_id=435495)（月額 100 ドル） {#1-the-silver-tier-100month}
特典：

1. [Scrapling のプロジェクトページ上部](https://github.com/D4Vinci/Scrapling?tab=readme-ov-file#sponsors)にロゴを掲載します。
2. 同じロゴを [PyPI ページの上部](https://pypi.org/project/scrapling/)と [Docker イメージのページ](https://hub.docker.com/r/pyd4vinci/scrapling)にも、プロジェクトページと同じように掲載します。

### 2. [Gold プラン](https://github.com/sponsors/D4Vinci/sponsorships?tier_id=591422)（月額 200 ドル） {#2-the-gold-tier-200month}
特典：

1. [Scrapling のプロジェクトページ上部](https://github.com/D4Vinci/Scrapling?tab=readme-ov-file#sponsors)にロゴを掲載します。
2. 同じロゴを [PyPI ページの上部](https://pypi.org/project/scrapling/)と [Docker イメージのページ](https://hub.docker.com/r/pyd4vinci/scrapling)にも、プロジェクトページと同じように掲載します。
3. [Scrapling のウェブサイト](https://scrapling.readthedocs.io/ja/latest/)の主なスポンサー欄にもロゴを掲載します。

### 3. [Platinum プラン](https://github.com/sponsors/D4Vinci/sponsorships?tier_id=586646)（月額 300 ドル） {#3-the-platinum-tier-300month}
特典：

1. [Scrapling のプロジェクトページ最上部](https://github.com/D4Vinci/Scrapling?tab=readme-ov-file#platinum-sponsors)の目立つ場所にロゴを掲載し、25 単語までの紹介文を添えます。
2. 同じロゴを [PyPI ページ](https://pypi.org/project/scrapling/)と [Docker ページ](https://hub.docker.com/r/pyd4vinci/scrapling)にも、プロジェクトページと同じように掲載します。
3. [Scrapling のウェブサイト](https://scrapling.readthedocs.io/ja/latest/)の主なスポンサー欄でロゴを目立つように掲載します。
4. Discord でパートナーロールを付与し、Twitter と Discord で紹介します。
5. 各リリースノートの末尾にスポンサーとして名前を掲載します。
