# Response-Klasse {#response-class}

Die Klasse `Response` enthält die HTTP-Antworten aller Fetcher. Sie bietet Zugriff auf Status, Header, Inhalt und Cookies sowie einen `Selector` zum Auswerten der Antwort.

So importieren Sie die Klasse `Response`:

```python
from scrapling.engines.toolbelt.custom import Response
```
